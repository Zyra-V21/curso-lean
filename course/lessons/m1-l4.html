Para todo y existe

En una frase: ∀ significa «para todos, sin excepción» y ∃ significa «al menos uno»; un solo contraejemplo tumba un «para todo», y un solo testigo basta para un «existe».

Por qué te importa: «el contrato funciona para toda entrada» y «existe una entrada para la que funciona» suenan parecido y no se parecen en nada. Cambiar uno por otro es una de las formas más baratas de que un teorema prometa mucho menos de lo que parece.

Para todo: sin excepciones

«Todos los jugadores de la raid tienen nivel 80.» Para que sea verdad, tienen que cumplirlo todos. Basta uno de nivel 79 para que sea falso. Ese jugador es un contraejemplo: un caso concreto que rompe el «para todo».

Existe: con uno basta

«Hay al menos un jugador de nivel 80 en la raid.» Para que sea verdad basta con señalar a uno. Ese caso que lo demuestra se llama testigo.

En Lean, «existe» se escribe ∃.

Ojo: ∃ promete muchísimo menos que ∀. «Existe una entrada para la que el contrato no pierde dinero» se cumple aunque el contrato pierda dinero con todas las demás. Si pediste «para todo» y te entregan «existe», no es lo que pediste.

¿Para todos los qué? El dominio importa

Detrás de cada ∀ hay un tipo de cosas: el dominio. Cambiarlo cambia la verdad de la frase.

#check ∀ n : Nat, 0 ≤ n  --> ∀ (n : Nat), 0 ≤ n : Prop
#check ∀ n : Int, 0 ≤ n  --> ∀ (n : Int), 0 ≤ n : Prop

La primera es verdad: los naturales (0, 1, 2...) nunca son negativos. La segunda es falsa: entre los enteros está el -1, un contraejemplo.

Si no se escribe el tipo, como en ∀ n, 0 ≤ n, Lean lo elige solo: como hay números, elige Nat. Como auditor, comprueba qué dominio se eligió; #check te lo enseña:

#check ∀ n, 0 ≤ n  --> ∀ (n : Nat), 0 ≤ n : Prop

Aquí no usamos decide: con números sin tope, Lean no puede comprobarlos uno a uno porque son infinitos, y responde con un error (failed to synthesize). Para lo infinito hace falta una demostración de verdad.

#eval decide (∀ n : Nat, 0 ≤ n)

El orden importa

Compara estas dos frases:

  • «Todo el mundo tiene una madre.» Para cada persona, existe alguien que es su madre. Verdad.
  • «Existe una madre de todo el mundo.» Hay una sola persona que es madre de todos. Falso.

Negar un «para todo»

«No todos aprobaron» no significa «nadie aprobó». Significa «alguien suspendió». Negar un «para todo» da un «existe uno que no».

Y al revés: «no existe nadie que haya copiado» es lo mismo que «para todo alumno, ese alumno no copió».

#eval decide (¬ ∀ n, n < 10 → n * n < 50)  --> true
#eval decide (∃ n, n < 10 ∧ ¬ (n * n < 50))  --> true

Las dos dicen lo mismo: no todos los números menores que 10 tienen el cuadrado menor que 50, porque existe alguno (el 8, por ejemplo) que no.

El jefe, hoy

Hoy despejas dos piezas del jefe: ∃ witness : List R, y ∀ w',.

Juntas se leen así: «existe un testigo witness tal que abre el compromiso, y para todo w' que también lo abra, w' es ese mismo testigo». Es decir: hay un testigo, y es el único.

Llévate esto

  • ∀ es «para todos»: un contraejemplo lo tumba. ∃ es «al menos uno»: un testigo lo demuestra.
  • Mira el dominio y el orden: ∀ x, ∃ y no es ∃ y, ∀ x.
  • «No todos» es «alguno no». Y un ∃ donde pediste un ∀ promete mucho menos.
